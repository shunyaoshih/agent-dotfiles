# Notifications

When a task runs more than a few minutes (builds, full test runs, installs)
or you need my decision to continue, send a push notification when it
finishes or blocks. Lead with what I'd act on ("tests failed: 2 in
NoteTests", not "done"). It only reaches my phone when the terminal isn't
the frontmost app, so send it anyway; the tool skips it when redundant.
